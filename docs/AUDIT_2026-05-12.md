## 已修复问题

- 配置逻辑分散：新增 `src/config_manager.py`，统一默认配置、嵌套配置合并、配置路径定位、运行时路径解析和 Web 配置更新白名单清洗。
- 配置相对路径修正顺序错误：`processed_files_log` 和 `log_file` 过去会在路径修正前被读取或创建，导致记录文件和日志可能落到不同目录。现在先解析路径，再加载处理记录和初始化日志。
- 队列并发不符合配置：`max_concurrent_processes` 过去无法稳定驱动多个 worker，并存在重复启动队列线程的竞态。现在按队列长度和并发上限补足 worker，并通过锁生成状态快照。
- 正在运行的 LADA 子进程缺少停止策略：现在记录活动子进程，停止接口可选择 `terminate_running` 强制终止。
- Web 动态内容注入风险：队列文件名、目录路径过去直接拼进 `innerHTML`。现在改为 DOM API 和 `textContent` 渲染，避免路径名中的 HTML 被执行。
- 本机路径操作风险：Web 服务过去默认对外监听且允许远程请求触发打开本机路径/文件夹选择器。现在默认只监听 `127.0.0.1`，限制这些本机操作接口只接受本机请求，并为非本机访问增加 token 控制。
- 配置更新缺少输入校验：现在对 JSON 结构、数字范围、布尔值、路径列表和 LADA 选项做统一白名单清洗，避免无效 payload 直接写入配置。
- 前端维护成本高：`src/templates/index.html` 的内联 CSS/JS 已拆分为 `src/static/app.css`、`src/static/app.js` 和精简后的模板。
- 仓库边界不清：扩展 `.gitignore`，忽略 `.venv/`、`cli/`、日志、运行数据、真实配置和打包产物；新增 `docs/RELEASE_ARTIFACTS.md` 说明发布产物边界。
- UI/UX 稳定性：移除装饰性光斑背景，收敛为操作台风格；补充焦点可见状态、`prefers-reduced-motion`、移动端布局约束和更稳定的卡片半径。
- 启动脚本可靠性：Windows Web/监控启动脚本现在先切到脚本目录，避免从其他工作目录调用时找不到相对路径。

## 设计改进建议
